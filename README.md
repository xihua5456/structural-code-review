# 结构规范核查

版本：1.3

一个用于钢筋混凝土房屋结构计算书技术自查的 Agent Skill。以 GB、GB/T 国家标准为固定查阅目录，核对规范版本、参数来源、公式适用与图算一致性，输出问题清单和审图回复草稿。

## 包含内容

- `SKILL.md`：四关审查流程及输出要求。
- `references/规范目录.md`：按事项分类的 28 项国家标准名称及查阅提示。
- `references/审查报告模板.md`：审查记录、确认问题、待核事项及回复模板。
- `LICENSE`：MIT 许可。

## 在 Codex 中使用

将整个 `structural-code-review` 文件夹放入个人技能目录 `~/.agents/skills/`，或项目中的 `.agents/skills/`。目录下应直接包含 `SKILL.md` 和 `references/`。

在 Codex 中输入：

```text
$structural-code-review 审查这份结构计算书，先核对规范依据，再检查配筋与图算一致性。
```

提供需要审查的计算书；有相关图纸、勘察资料和规范原文时一并提供。按审查范围使用资料，缺少依据的事项会列为待核。

## 工作方式

1. 确认项目条件、版本和本次审查范围。
2. 从规范目录选择相关标准，查阅适用版本的原文。
3. 核对参数、模型、公式条件及数值和图纸的一致性。
4. 输出可定位、有依据的问题清单与整改回复草稿。

本技能不附规范原文或限值库。规范名称用于检索，具体条款和数值在使用时核对。
